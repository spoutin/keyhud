# Design Specification: Export Cheatsheet to Markdown

## 1. Intent & Purpose
Users often want to keep an offline reference sheet of their shortcuts, print them, or paste them into notes (Obsidian, Notion, GitHub wikis, etc.). 
This feature adds an **Export to Markdown** button in the KeyHUD header (and in Settings) that generates clean, well-formatted GitHub-flavored Markdown tables of the currently viewed cheatsheet and offers:
1. **Save to File**: Saves a `.md` file to `~/Documents/KeyHUD/<app-name>-shortcuts.md` and opens/reveals it in Finder.
2. **Copy to Clipboard**: Copies the Markdown directly to the system clipboard for immediate pasting.

---

## 2. Requirements & Markdown Formatting

### 2.1 Output Format
For the current app/scope and its groups:
```markdown
# [App Name] Cheatsheet

Generated by KeyHUD on [Date]

## [Category Title]

| Action | Shortcut |
| :--- | :--- |
| [Item Title] | `[Keys]` |
| ... | `...` |

...
```
If favorites are present in the active view, they can be listed under `## ⭐ Favorites` at the very top.

### 2.2 User Interface
- An **Export** button in the HUD header right beside the Settings and Pin buttons:
  - Icon: `square.and.arrow.up` (Share / Export icon).
  - Shows a compact menu or sheet:
    - **Copy Markdown to Clipboard** (with visual confirmation toast / button feedback).
    - **Save to Documents** (writes to `~/Documents/KeyHUD/<name>-shortcuts.md` and reveals in Finder).

---

## 3. Architecture & Data Flow
- `MarkdownExporter`:
  - `static func generateMarkdown(appName: String, groups: [ShortcutGroup]) -> String`
  - `static func saveToDocuments(appName: String, markdown: String) -> URL?`
  - `static func copyToClipboard(markdown: String)`
